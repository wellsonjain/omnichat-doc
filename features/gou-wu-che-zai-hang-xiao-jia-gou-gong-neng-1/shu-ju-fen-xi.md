# 數據分析

此處分別呈現了 <mark style="color:blue;">**LINE / Facebook / WhatsApp**</mark> 三種購物車再行銷中，每一則訊息的啟用狀態。以及特定時間區間內，每一則行銷訊息 <mark style="color:blue;">**送出訊息數 / 點擊數 / 點擊率 / 訂單數 / 營業額 / 廣告投資報酬率（ROAS） / 轉換率**</mark> 等數據。藉由這些資料，品牌方可以再優化訊息中的內容，藉此增進相關指標。

#### 1. 日期區間分析

下拉選單後，你可以自訂你要查詢的時間區間，分別查看 **每天 / 每週 / 每月** 的數據變化。

#### 2.  數據指標

* 點擊率：點擊率＝點擊數 / 送出訊息點擊數＝可追蹤點擊的訊息第一次點擊數（不重複點擊數）
* 訂單：透過 Pixel 追蹤，以 UTM 判斷是否透過購物車再行銷訊息完成購買
* 營業額：總計該訊息訂單金額
* 廣告投資報酬率：營業額 / 送出訊息成本訊息成本計算
* 轉換率：訂單數 / 不重複點擊數
