# 顧客檔案

{% hint style="info" %}
此功能原名稱：顧客管理
{% endhint %}

## 顧客檔案介面

<figure><img src="../../.gitbook/assets/截圖 2025-09-26 下午2.40.52 (1).png" alt=""><figcaption></figcaption></figure>

1. 整合官網顧客於渠道被貼上的標籤。
2. 整合官網顧客於不同渠道蒐集到的自訂屬性。
3. **搜尋：**&#x53EF;依照特定條件搜尋出特定顧客
4. **更多功能：**
   1. **匯出：**&#x8CC7;料項目包括：姓名、會員編號、電話、Email、標籤、聯絡人建立時間
   2. **匯入：** 關於匯入顧客資料請參閱 "[匯入顧客資料](https://docs.omnichat.ai/features/she-qun-ke-hu-zi-liao-ping-tai/hui-ru-gu-ke-zi-liao)"

{% hint style="info" %}
自訂屬性（Custom Attribute）：為品牌端自定義欄位，可存入資料。
{% endhint %}
