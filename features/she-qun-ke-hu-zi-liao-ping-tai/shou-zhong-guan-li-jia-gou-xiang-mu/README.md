## 受眾包設定方式

### 1. 建立受眾包

路徑位於左欄的 「 社群客戶資料平台 」 下找到 「 受眾分群 」，點擊右上角按鈕建立受眾包。

<figure><img src="../../../.gitbook/assets/截圖 2025-09-30 下午4.51.32.png" alt=""><figcaption></figcaption></figure>

### 2. 受眾包設定

<figure><img src="../../../.gitbook/assets/截圖 2025-09-30 下午4.54.01 (1).png" alt=""><figcaption></figcaption></figure>

**a. 受眾包名稱：**&#x9810;設格式為 「 YYYY-MM 新受眾包 」 ，名稱無字數限制，可依照需求自行輸入

**b. 篩選條件**

* 通訊渠道，此為必填欄位，請點選需要的社群渠道
* 新增條件：需至少須設定一個條件
* 所有條件範圍

<table><thead><tr><th width="239">條件範圍</th><th>條件</th></tr></thead><tbody><tr><td><strong>顧客資料</strong></td><td><ol><li>標籤 </li><li>自訂屬性 </li><li>姓名 </li><li>電話 </li><li>會員編號 </li><li>Email</li></ol></td></tr><tr><td><strong>時間相關</strong></td><td><ol><li>加入訂閱時間</li></ol><ol start="2"><li>客人最後互動時間：顧客傳送訊息、與機器人互動、訂閱渠道的互動時間</li><li>團隊最後行銷時間：行銷相關自動推播、群發訊息的時間</li><li>團隊最後互動時間：團隊傳給顧客一對一訊息的時間</li><li>最後完成結帳時間</li><li>最後開封推播時間</li><li>最後點擊推播時間</li></ol></td></tr><tr><td><strong>互動情況</strong></td><td><ol><li>手機綁定</li><li>官網綁定</li><li>開封推播</li><li>點擊推播</li></ol></td></tr><tr><td><p><strong>OMO相關</strong></p><p><strong>（使用OMO方案才會顯示）</strong></p></td><td><ol><li>OMO 綁定狀態</li><li>OMO 綁定成員</li><li>OMO 綁定分店</li></ol></td></tr></tbody></table>



3. **符合目前條件的顧客數：**

* **更新人數**：篩選完條件後系統會重新運算當下符合條件的人數
* **查看名單**：
  * 點擊後預覽受眾名單：顯示對應條件的社群聯絡人資料
  * 名單排序方式：聯絡人最後更新時間由近到遠排序
  * 系統會自動排除超額名單和取消訂閱的聯絡人
  * 點擊 「 查看名單 」 或符合條件的人數後，會顯示受眾名單列表，若要查看受眾的詳細資料，可於名單右側欄位點選 「 動作 」。

<figure><img src="../../../.gitbook/assets/截圖 2025-09-30 下午4.55.25 (1).png" alt=""><figcaption></figcaption></figure>



4. **建立：**&#x7BE9;選好受眾條件後，點擊右上角的 「 建立 」 按鈕，接著您可以選擇 「 回到列表頁 」，或者直接以此受眾包 「 立即推播 」。

<figure><img src="../../../.gitbook/assets/截圖 2025-09-30 下午4.57.01.png" alt=""><figcaption></figcaption></figure>

## 受眾分群列表

<figure><img src="../../../.gitbook/assets/截圖 2025-09-30 下午4.57.18 (1).png" alt=""><figcaption></figcaption></figure>

1. **受眾包名稱：**&#x9810;設排列為由上到下<mark style="color:red;">**依建立時間由近到遠排序**</mark>，再次點擊名稱則會改為由遠到近排序
2. **通訊渠道：**&#x4C;ine、Facebook、Instagram、WhatsApp
3. **類型：**&#x689D;件篩選
4. **動作**
   1. 編輯
   2. 複製
   3. 封存
   4. 推播
   5. 上傳受眾到 LINE 廣告
5. **搜尋：**&#x53EF;使用關鍵字搜尋受眾包名稱
6. **篩選：**&#x7BE9;選各渠道受眾包
7. **啟用中的受眾包**
