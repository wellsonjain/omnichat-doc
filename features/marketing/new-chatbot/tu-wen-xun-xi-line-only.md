# 圖文訊息（LINE only）

## 確認機器人的平台為 LINE 限定後，可在新增模組列表中選擇 「圖文訊息」 卡片

<figure><img src="../../../.gitbook/assets/截圖 2025-03-20 晚上7.28.44.png" alt=""><figcaption></figcaption></figure>

## 可選擇使用現有的或是建立新的圖文訊息

<figure><img src="../../../.gitbook/assets/截圖 2025-03-20 晚上7.34.12.png" alt=""><figcaption></figcaption></figure>

1. 選擇圖文訊息後可以預覽畫面
2. 點擊下拉式選單，可以找到過去建立過的圖文訊息，並且支援搜尋圖文訊息名稱。或是選擇 「新增圖文訊息」 來開啟編輯介面

{% hint style="info" %}
若選擇過去建立過的圖文訊息，介面會顯示該圖文訊息中設定的動作內容。

點擊右上角的 「查看」，可以在介面中直接編輯圖文訊息的內容

<img src="../../../.gitbook/assets/截圖 2025-03-20 晚上7.41.01.png" alt="" data-size="original">
{% endhint %}
