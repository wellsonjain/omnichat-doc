# 發票模組（加購功能） ( LINE only )

💡 **此頁介紹機器人2.0中的發票模組卡片設定，關於發票模組的設定教學，請前往**[**這個連結**](https://docs.omnichat.ai/features/fa-piao-mo-zu-jia-gou-gong-neng)**。**

### 新增發票模組機器人卡片

* 發票模組僅支援 LINE 平台。
* 若需使用發票模組卡片，請先重新新增一隻機器人，適用平台選擇 「 **LINE** 」。

<figure><img src="../../../.gitbook/assets/截圖 2025-03-18 上午11.20.15.png" alt="" width="563"><figcaption><p>適用平台選擇 「 LINE 」</p></figcaption></figure>

### 卡片內容設定

* 一個機器人模組僅能設定一個發票模組，若設定多個，會以最後一個發送給客戶的發票模組為主。

<figure><img src="../../../.gitbook/assets/機器人2.0拷貝2 (1).png" alt=""><figcaption><p>一個機器人模組僅能設定一個發票模組</p></figcaption></figure>
