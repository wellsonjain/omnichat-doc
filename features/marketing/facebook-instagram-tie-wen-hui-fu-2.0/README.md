# Facebook / Instagram 貼文回覆 2.0

Omnichat 支援製作 Facebook / Instagram 貼文留言自動回覆及貼文私訊回覆功能，讓用戶可以透過 Omnichat 製作 Facebook / Instagram 貼文自動廣告活動

<figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

## 設定前注意事項

{% hint style="warning" %}
請留意，如欲使用「Facebook 貼文回覆」功能，必須是以 Facebook 粉專管理員身份登入Facebook 粉絲專頁的狀態下才能使用，若非登入狀態則不能使用。
{% endhint %}

## 列表頁面說明 <a href="#ru-he-she-ding-facebook-instagram-tie-wen-hui-fu-huo-dong" id="ru-he-she-ding-facebook-instagram-tie-wen-hui-fu-huo-dong"></a>

<figure><img src="../../../.gitbook/assets/截圖 2025-05-17 下午1.41.30.png" alt=""><figcaption></figcaption></figure>

1. 搜尋欄位：快速搜尋活動名稱。
2. 新增活動：詳細設定步驟請見[下方說明](./#ru-he-she-ding-facebook-instagram-tie-wen-hui-fu-huo-dong-1)。
3. 活動期間：設定的有效期間過後就不再觸發，若沒有要設定時限，則選取永久啟用。
4. 留言回覆：目前已觸發的貼文留言回覆數量。
5. 私訊回覆：目前已觸發的私訊回覆數量。
6. 建立時間：活動建立時間。
7. 狀態：分為「草稿」、「進行中」、「暫停中」。
   * 草稿：草稿狀態下的貼文可以進去編輯修改貼文，一但發布之後只能暫停。
   * 進行中
   * 暫停中：只要按下暫停即會顯示，即便符合自動回覆條件也不會觸發。
8. 動作：可執行「編輯」、「暫停」兩項動作。

## **如何設定** Facebook / Instagram 貼文回覆活動 <a href="#ru-he-she-ding-facebook-instagram-tie-wen-hui-fu-huo-dong" id="ru-he-she-ding-facebook-instagram-tie-wen-hui-fu-huo-dong"></a>

### 步驟一：**新增活動與基本設定** <a href="#bu-zhou-1-xin-zeng-huo-dong" id="bu-zhou-1-xin-zeng-huo-dong"></a>

點選頁面右上角&#x7684;**「＋新增活動」**&#x6309;鈕，進&#x5165;**「基本設定」**&#x9801;面。

<figure><img src="../../../.gitbook/assets/截圖 2025-05-17 下午1.59.07.png" alt=""><figcaption></figcaption></figure>

1. 輸入活動名稱
2. 選擇社群平台
3. 選擇內容：Facebook與Instagram目前暫時<mark style="color:red;">**不支援排程中貼文**</mark>
   * 在清單中選擇貼文
     * 只會顯示 Facebook 粉專最近 **50** 篇「**已發佈**」的貼文，Instagram 則是顯示近期 **25** 篇「**已發佈**」的貼文。
     * 可點擊右側的箭頭按鈕快速開啟該貼文頁面。
   * Facebook可手動輸入貼文編號：<mark style="color:red;">**請勿直接貼上貼文網址上的編號**</mark>，正確設定方式請見[此頁面說明](how-to-get-facebook-post-id.md)。
   * Instagram除了貼文，可另外支援直播留言、限時動態提及、IG 廣告。
   * 全部貼文或內容
     * 若新增「全部貼文」的活動選項，可以當作所有貼文預設的自動回覆。
     * 若同時有「全部貼文」與「特定貼文」的活動，會以「特定貼文」的自動回覆為優先。
     * 若有多個「全部貼文」的活動，會以最新建立的自動回覆為優先。
4. 活動期間：設定的有效期間過後就不再觸發，若沒有要設定時限，則選取永久啟用。
   * Instagram選擇「直播留言」只能設定排程時間，在設定時間內的直播都會觸發私訊自動回覆。

### 步驟二：貼文回覆/私訊回覆設定

點擊左側「回覆設定」來調整貼文回覆/私訊回覆的內容。

<figure><img src="../../../.gitbook/assets/截圖 2025-05-17 下午1.59.16.png" alt=""><figcaption></figcaption></figure>

{% hint style="info" %}
設定時請留意，在 Facebook / Instagram 貼文回覆活動中的關鍵字條件，英文字母與數字符號的**大、小寫，全形及半形，均會視為不同的字元。**

舉例來說：

情況一：`ABC` (半形且大寫) ，`ＡＢＣ` (全形)、`abc`（小寫），三者均為不同的關鍵字條件

情況二：關鍵字設定為 `abc`（半形）

客人回覆答案為：`abc` > 這個會觸發貼文/私訊回覆活動

客人回覆答案為：`Abc / ABC / aBC / ａｂｃ` > 這些不會觸發貼文 / 私訊回覆活動
{% endhint %}

1. 顧客留言：設定觸發自動回覆的內容。
   * 為所有內容：不用設定關鍵字，在貼文下方留言任何內容（包含表情符號 / 圖片 / 貼圖），即會觸發自動回覆。
   * 包含任一：若有設定多個關鍵字時，僅需符合其中一個關鍵字，即可觸發自動回覆。
     * 例如：若設定「包子」、「漢堡」，共兩組關鍵字，客人輸入「我想吃**包子**」就會觸發自動回覆。
   * 包含全部：若有設定多個關鍵字時，需要符合所有關鍵字，才可觸發自動回覆。
     * 例如：若設定「包子」、「漢堡」，共兩組關鍵字，客人輸入「**包子**與**漢堡**我都要」才會觸發自動回覆。
   * 內容完全一致：貼文下方的回覆內容需跟後台設定的**一模一樣**，建議設定一個關鍵字詞或句子即可。
     * 例如：若設定「包子跟漢堡都超讚」，客人輸入「包子超好吃」就不會觸發自動回覆。
2. 標記好友數：僅有Facebook專頁有提供此功能。
3. 觸發動作：分為「貼文留言回覆」與「私訊回覆」，詳細設定請見[下方說明](./#chu-fa-dong-zuo-she-ding-shuo-ming)。
   * 需選擇貼文留言回覆或私訊回覆其中之一，設定至少一組回覆內容。
   * 若設定為Instagram的直播留言、限時動態提及、全部內容時，僅提供私訊回覆。
4. 新增回覆：可新增多組不同的回覆內容。
   * 同一條件下，設定多組回覆內容時，系統將隨機發送。
   * 建議設定多組且多樣化的留言回覆，可降低被 Meta 阻擋或誤判為垃圾訊息的機率。
5. 新增回覆條件：須至少設定一組回覆條件，可新增多組不同的回覆條件。

### 觸發動作設定說明

#### 貼文回覆設定

<figure><img src="../../../.gitbook/assets/截圖 2025-05-18 上午11.47.33.png" alt=""><figcaption></figcaption></figure>

1. 點擊「貼文留言回覆」分頁。
2. 點擊「新增回覆」。
3. 設定要回覆的圖文內容，可點擊文字訊息框右下角添加姓名參數自動顯示聯絡人名稱與表情符號。
4. 若要刪除目前設定的回覆內容，可點擊右上角的垃圾桶按鈕。

#### 私訊回覆設定

<figure><img src="../../../.gitbook/assets/截圖 2025-05-18 上午11.46.23.png" alt=""><figcaption></figcaption></figure>

1. 點擊「私訊回覆」分頁。
2. 點擊「新增回覆」。
3. 以機器人卡片模組回覆（注意：因為 Facebook 的限制，只可以回覆**包含 1 張卡片**的模組，建議使用有按鈕的卡片，可提高用戶跟粉專的互動率）
4. 以純文字私訊回覆，可以添加姓名參數自動顯示聯絡人名稱與表情符號。
5. 若要刪除目前設定的回覆內容，可點擊右上角的垃圾桶按鈕。

### 步驟三：點擊儲存或發布

確認都設定完成後，即可點擊頁面右上角「儲存」或「發布」囉！

<figure><img src="../../../.gitbook/assets/截圖 2025-05-18 下午12.15.05.png" alt=""><figcaption></figcaption></figure>

點擊「儲存」按鈕：會先將目前設定內容儲存起來，活動為「草稿」狀態，仍可以在針對內容進行調整。

點擊「發布」按鈕：活動即會正式啟用，之後就只能暫停。
