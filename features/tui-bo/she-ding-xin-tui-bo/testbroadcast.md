# 發送測試訊息

<figure><img src="../../../.gitbook/assets/截圖 2025-10-17 上午10.53.26.png" alt=""><figcaption></figcaption></figure>

## 建立測試名單

{% hint style="info" %}
測試名單人數無上限
{% endhint %}

<figure><img src="../../../.gitbook/assets/截圖 2025-10-17 上午11.20.56.png" alt=""><figcaption></figcaption></figure>

1. 先到 「 渠道聯絡人 」 搜尋出要設定的測試人員資訊。
2. 勾選想要加入到測試名單的聯絡人後，再點擊右側的 「 更多功能 」 － 「 新增至測試名單 」 。
3. 點擊 「 新增至測試名單 」 後，會出現確認頁面，點擊 「 新增 」 後即新增完成。

<figure><img src="../../../.gitbook/assets/截圖 2024-06-28 上午10.57.20.png" alt="" width="375"><figcaption><p>確認資料無誤，可以點擊 「 新增 」</p></figcaption></figure>

4. 新增完成後，聯絡人姓名下方會顯示 `測試名單` &#x20;

## 發送測試推播訊息

{% hint style="info" %}
1. 每次發送測試訊息，一次最多為 5 位，若需要發送超過 5 位，請分為發送兩次測試訊息
2. 發送測試訊息，<mark style="color:red;">**不會在推播總覽頁面中出現相關數據**</mark>
{% endhint %}

1. 先到 「 推播 」 安排新推播，將推播資料設定好後，點擊 「 發送測試訊息 」。

<figure><img src="../../../.gitbook/assets/截圖 2025-10-17 上午10.53.26 (1).png" alt=""><figcaption></figcaption></figure>

2. 點擊 「 發送測試訊息 」 後，會跳出確認測試人員名單的畫面。

<figure><img src="../../../.gitbook/assets/截圖 2025-10-17 上午10.57.18.png" alt="" width="375"><figcaption></figcaption></figure>

{% hint style="info" %}
點擊 「 管理名單 」，可以**查看或刪除**目前的測試人員名單。

![](<../../../.gitbook/assets/截圖 2025-10-17 上午11.29.30 (1).png>)
{% endhint %}

3. 確認推播測試人員後勾選，再點擊 「 發送測試訊息 」。

<figure><img src="../../../.gitbook/assets/截圖 2024-06-28 上午11.09.59.png" alt="" width="375"><figcaption></figcaption></figure>

4. 點擊 「 發送測試訊息 」後，訊息就會直接排程發送，發送完成會跳出 「 測試訊息已送出 」 的通知。

<figure><img src="../../../.gitbook/assets/截圖 2024-06-28 上午11.17.15.png" alt=""><figcaption></figcaption></figure>

5. 最後只需要到您的推播渠道上，查看推播的內容是否符合您的設計，若沒問題即可以安排正式推播。

<figure><img src="../../../.gitbook/assets/測試訊息.jpg" alt=""><figcaption><p>推播內容查看</p></figcaption></figure>
