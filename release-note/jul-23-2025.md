哈囉，親愛的 Omnichat 用戶！

為你帶來一個好消息，我們的 LINE 會員卡，支援顯示 Shopify 的訂單囉！

Omnichat 的會員卡模組，支援四大功能：

* **會員中心**：透過電商平台整合、API 串接整合會員資料到 Omnichat，並可以顯示在會員卡上
* **優惠券夾**：顯示優惠券
* **我的訂單**（僅支援 LINE）：支援 SHOPLINE、CYBERBIZ、Shopify 訂單顯示，也支援第三方平台透過 API 串接訂單資料
* **手機綁定**（僅支援 LINE）：綁定顧客 LINE UID 與手機號碼

立即開始使用會員卡模組，讓顧客在 LINE、WhatsApp 獲得無縫的會員體驗。
