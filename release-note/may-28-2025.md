## LINE 群組對話功能上線！

大家期待已久的 LINE 群組對話功能上線囉！

所有包含客服的方案，皆支援 LINE 群組對話功能，讓品牌可以更方便一次服務多位顧客。

### 前置作業

需至 LINE 開發者控制台 > Message API 選項，啟用允許機器人加入群組聊天，才可以被加入群組。 未啟用時，顧客加入官方帳號進群組 LINE 系統會自動將官方帳號踢出。

<figure><img src="../.gitbook/assets/LINE 群組對話1.png" alt=""><figcaption></figcaption></figure>

### 操作須知

LINE API 不支援建立群組、主動加入群組。

* 官方帳號加入群組：
  * **需由個人帳號建立群組後，手動將官方帳號加入**
  * 在群組內的成員皆可將 LINE 官方帳號加入群組，不需經由品牌同意。
  * 無法知道是由哪位成員加入群組。
  * 群組對話會進到「待處理真人客服」。
* 邀請其他好友加入群組：
  * LINE 官方帳號無法主動加其他成員
  * 需由個人帳號邀請其他好友加入
* 官方帳號退出群組
  * 包含主動退出群組和被群組成員退出兩種狀況。
  * 退出後群組的處理：
    * 群組對話會自動變為已結束。
    * 有釘選狀態時會自動解除。
    * 無法重啟對話。
    * 群組對話紀錄會被保留，但無法發送訊息。
    * 群組人數會顯示 0。
    * 藍盾、綠盾方案的團隊會無法查看原群組成員名單。
* 支援一對多、多對多群組
  * 一對多：一般群組對話
  * 多對多（協作群組）：群組對話新增協作者
* 銷售經理、銷售人員暫時無法使用 (會看不到群組對話)。

### 訊息費用

* 品牌在群組內發送 LINE Message 是以群組人數計算訊息量。
* push message 發送次數\*群組人數 = 實際訊息用量

使用個人帳號發送訊息則不計費，若要節省訊息費用，可以多利用群組中的品牌方人員個人帳號發送訊息。
