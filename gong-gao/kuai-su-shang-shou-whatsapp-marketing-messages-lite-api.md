# 快速上手 WhatsApp Marketing Messages Lite API

Meta 推出了全新優化的 **Marketing Messages Lite API（簡稱 MM Lite API）**，讓企業能更有效率地發送 **WhatsApp 行銷訊息**。

Omnichat 已全面升級採用此解決方案，**所有客戶需於 2025 年 7 月 30 日前完成啟用，才能繼續使用 WhatsApp 行銷訊息範本。**

#### 為什麼 MM Lite 很重要？

* **提升訊息送達率、閱讀率與點擊表現**
* **無須變動** 現有的行銷操作流程
* Omnichat 使用者 **需完成啟用**，才能在 7 月 30 日後繼續發送 WhatsApp 行銷訊息範本

### 什麼是 Marketing Messages Lite API？

**MM Lite API** 是 Meta 為 WhatsApp 行銷訊息設計的新一代發送 API，能更快、更有效地傳遞行銷活動。

#### ✅ 主要優勢：

* **提升送達率**：系統自動優化，高品質訊息相比 Cloud API 有更高送達可能性
* **完整互動數據**：可透過 Business Management API 與 WhatsApp Manager 介面查看發送、送達、閱讀與點擊等數據
* **轉換追蹤能力**：整合 Meta Pixel 或 Conversions API，即可追蹤訊息點擊後的用戶行為（如購買），並在 Meta 後台查看投資報酬率（ROI）
* **專屬功能**：部分行銷專用功能僅限 MM Lite API 提供，Cloud API 不支援

### 無痛升級，流程完全不變

切換至 MM Lite 不需要更改任何設定或操作方式：

* ✅ 可**沿用所有現有行銷訊息範本**
* ✅ Omnichat 中的 **推播流程與自動化設定** 完全不變
* ✅ 開通後，Omnichat 會**自動將行銷訊息導入 MM Lite 通道**

### MM Lite API 與 Cloud API 差異比較

| 功能      | MM Lite API            | Cloud API     |
| ------- | ---------------------- | ------------- |
| 行銷推播    | ✅ 優化版                  | ⚠️ 傳統版本（即將淘汰） |
| 發送優化    | ✅ 支援                   | ❌ 不支援         |
| 點擊與閱讀追蹤 | ✅ 支援                   | ✅ 支援          |
| 轉換追蹤    | ✅ 支援（需整合 Pixel / CAPI） | ❌ 不支援         |
| 用戶回覆支援  | ❌ 不支援                  | ✅ 支援          |

**我們將會繼續同時使用 MM Lite API 和 Cloud API。**

所有「行銷類型訊息範本」將透過 **MM Lite API** 發送，而其他所有訊息類型（包括服務型、工具型、驗證型訊息，以及使用者的回覆訊息）則會如以往一樣，透過 **Cloud API** 發送。

### 如何在 Omnichat 開啟 MM Lite API？

#### 若您是**現有客戶**（WABA 已連接 Omnichat）：

Omnichat 將於 6 月 18 日 啟動申請程序，Meta 將發送授權信件至您的帳號。



*   **誰會收到這封信？**

    所有 WhatsApp Business Account（WABA）所屬的 **Business Manager 最高權限管理員（BM Admin）**

自 **7 月 30 日起**，若未完成啟用 MM Lite API，將**無法發送任何 WhatsApp 行銷訊息範本**。
